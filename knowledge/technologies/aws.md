# AWS

Overview
- Cloud foundation for data platforms, compute, and storage.

Why I use it
- Provides broad primitives for scalable platform architecture.

When I choose it
- Data lakes
- ETL systems
- Cost-sensitive cloud architectures

When I avoid it
- When another cloud is already the better governance fit

Advantages
- Breadth of services
- Strong ecosystem

Disadvantages
- Service sprawl without architecture discipline

Alternatives
- Azure
- GCP

Enterprise considerations
- IAM, networking, and data access policies must be explicit.

Scaling considerations
- Right-size compute and storage tiers.

Common mistakes
- Leaving idle resources running

Best practices
- Automate infrastructure and lifecycle policies.

Related technologies
- Terraform, S3, Redshift
