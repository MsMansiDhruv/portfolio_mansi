# Azure

Overview
- Cloud platform that often appears in enterprise analytics and BI environments.

Why I use it
- Useful when the organization is already standardized on Microsoft tooling.

When I choose it
- Power BI ecosystems
- Microsoft identity and governance alignment

When I avoid it
- When another cloud already owns the platform and adding Azure adds duplication

Advantages
- Enterprise integration
- Identity and governance support

Disadvantages
- Another cloud can add operational spread

Alternatives
- AWS
- GCP

Enterprise considerations
- Identity, tenant governance, and service boundaries matter.

Scaling considerations
- Plan for managed services, networking, and access policies.

Common mistakes
- Spreading the platform across too many clouds without a reason

Best practices
- Align cloud choice to the operating model.

Related technologies
- Power BI, Databricks
