# Power BI

Overview
- Governed BI and semantic modeling platform for enterprise reporting.

Why I use it
- Fits Microsoft-centric enterprise analytics and self-service reporting.

When I choose it
- Executive dashboards
- Department reporting
- Governed semantic models

When I avoid it
- Pixel-perfect dashboarding
- Highly custom visualization requirements

Advantages
- Semantic models
- Azure integration
- Enterprise governance

Disadvantages
- DirectQuery latency
- Complex models need discipline

Alternatives
- Tableau
- Looker
- Superset

Enterprise considerations
- Licensing, workspace governance, and semantic ownership matter.

Scaling considerations
- Model size, refresh design, and gateway topology determine reliability.

Common mistakes
- Duplicating measures
- Pushing raw complexity into dashboards

Best practices
- Design star schemas and reusable measures.

Related technologies
- SQL, Azure, Databricks
